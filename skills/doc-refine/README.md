# 文档精修

`doc-refine` · 让现有技术文档更好找、更好读，同时保留必要信息。

## 何时使用

文档太长、标题模糊、重复较多，或准备发布前审阅。适合改善结构、措辞、图表与示例，不负责从零创建文档。

## 调用示例

```text
请读取 skills/doc-refine/SKILL.md，
先审阅这份文档的可读性，保留契约、警告和有效示例，只给修改建议。
```

## 会得到什么

审阅时得到可定位的建议；明确授权改写时得到精简后的文档与必要说明，并核对行为语义、链接和阅读效果。

不会因“代码里已有”删除行为契约、安全或法律警告、无障碍说明与有效示例。句长和被动语态等只作提示，不机械套用中文或强求数字达标。
