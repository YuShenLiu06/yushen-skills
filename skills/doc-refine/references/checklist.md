# 文档精修校验清单

按需用于审阅或授权改写后的检查。先检查信息与行为是否完整，再看可读性；不以分数、篇幅或关键词机械删文。

## 信息与授权

- [ ] 审阅只给建议；改写范围已有授权，事实或行为变化另行指出。
- [ ] 技术行为、API/数据契约、前提、边界条件、安全/法律警告完整。
- [ ] 无障碍替代说明、有效示例、有效链接和稳定锚点保留或有等效迁移。
- [ ] 没有因“代码里已有”删除读者仍需要的行为说明。
- [ ] 合并重复后，教程或独立页面仍能完成其任务；必要重复可保留。

## 语言初筛（建议，非验收线）

| 线索 | 检查方式 | 边界 |
|------|----------|------|
| 英文长句 | 约 20 词后留意嵌套与条件 | 不机械套用中文或改坏合同文本 |
| 段落过长 | 是否有多个主要观点 | 条件、例外与警告需要保持关联 |
| 长列表/步骤 | 是否能分组帮助定位 | 不为项数删除操作或恢复步骤 |
| 被动语态 | 读者能否知道主体和动作 | 不设比例红线；中文“被”不等于坏句 |
| 填充词 | 删除引导语是否仍清楚 | 保留其中的警告、限制和步骤信息 |
| 术语漂移 | 同义词是否指同一概念 | 不合并本来不同的领域概念 |

## 结构与消重

| 检查项 | 判断与处理 |
|--------|------------|
| 标题 | 脱离编号也能识别内容，调整前核对锚点和入站链接 |
| 主要任务 | 以教程、操作、参考或解释组织，必要背景可以保留或链接 |
| 前置条件 | 独立阅读者能找到所需概念、权限与环境要求 |
| 平行维护 | 同一事实多处独立维护时确定权威源，其他位置保留必要摘要或链接 |
| 行为说明 | 即使实现代码已表达，读者仍需的语义、限制与输出不能删 |

## 图表与示例

- [ ] 图比文字更清楚时才替换；目标平台不支持 Mermaid 时保留可用源格式或文字。
- [ ] 为分支条件与不明确的关系加标签，不要求每条顺序箭头都加字。
- [ ] 图在无视觉或无法渲染时仍有必要的文字替代，不能只用颜色传递语义。
- [ ] 宽表、密图按实际宽窄布局检查；不为节点/列数阈值删必要信息。
- [ ] 有效的入门、边界和错误恢复示例保留；合成示例清楚标记。
- [ ] 可运行示例包含必要依赖、输入和预期输出；省略部分有明确前提。
- [ ] 未运行或无法验证的示例如实标注，不冒充测试通过。

## 交付

报告具体改善、语义保留检查、链接/渲染结果和未验证项。审阅提供可定位建议；改写提供最小 diff，不以“变短了”代替文档正确。
