# LaTeX PDF 排版

`latex-pdf` · 在确需 LaTeX 时，交付可继续修改的源文件与经过实际检查的 PDF。

## 何时使用

用户明确选择 LaTeX，或需要它处理公式、参考文献等排版。普通文档、幻灯片和一般 PDF 导出不会自动切换到 LaTeX。

## 调用示例

```text
请读取 skills/latex-pdf/SKILL.md，
用 LaTeX 排版这份中文报告，保留源文件并检查实际 PDF 页面。
```

## 会得到什么

适合任务的引擎与排版设置、`.tex` 和所需资源、实际生成的 PDF，以及编译、页面检查和未验证项的记录。环境检测与包指南按需使用。

依赖安装按实际授权；不可信 TeX 先检查并隔离，默认禁用 shell-escape。编译成功不等于视觉验收，影响交付的警告须处理，无害项说明原因。
