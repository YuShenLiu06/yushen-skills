# 发布产物验收

`yushen-release-acceptance` · 从实际下载的最终产物，检查到用户真正可用。

## 何时使用

软件、安装器或桌面应用准备交付，或需要验证安装与授权是否仍会卡住。纯文案或内部小改动不必执行整套安装验收。

## 调用示例

```text
请读取 skills/yushen-release-acceptance/SKILL.md，
验收这个版本的下载、安装、启动和核心流程，区分平台与测试层级。
```

## 会得到什么

对应最终版本和文件哈希的验收记录，列出通过、失败、未测、阻塞和适用限制；实际 GUI、mock 与真实账户结果分开报告。

构建或 CI 成功不能代替用户路径验证，一端通过也不能覆盖另一平台。关键路径尚未验证或失败时，明确可用范围与预览限制。
