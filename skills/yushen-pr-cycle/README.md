# 需求到验收

`yushen-pr-cycle` · 把已确认的需求组织成可独立验证的小 PR，并追踪到本人验收。

## 何时使用

已明确委托软件开发，需要拆分功能、协调独立工作目录、自证、审查和组合验证时使用。普通讨论不会自动开始实现。

## 调用示例

```text
请读取 skills/yushen-pr-cycle/SKILL.md，
按已确认的需求推进开发，列清 PR 边界、证据和验收步骤。
```

## 会得到什么

功能边界与依赖、真实 PR、对应提交的运行证据、代码及安全审查记录，以及组合版本和最短验收步骤。附带可按需使用的 PR 模板与返工总结。

代码与安全共享最多三轮收敛，未解问题需要决策。合并须用户本人确认对应版本；本技能不额外授予费用、推送、合并或部署权限。
