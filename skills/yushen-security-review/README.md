# 独立安全审查

`yushen-security-review` · 沿实际调用链检查权限、隔离、数据与恢复边界。

## 何时使用

审查已授权 PR 中新增、放大或触发的安全风险，例如资源归属、不可信路径、模型嵌入内容、凭据泄漏和重复写入。

## 调用示例

```text
请读取 skills/yushen-security-review/SKILL.md，
对这个 PR 做只读安全审查，列出证据与未验证项。
```

## 会得到什么

包含触发条件、位置、证据、影响、最小建议和验证方式的发现；确认缺陷、待证实风险与建议分别呈现。

不自动改代码、攻击系统、访问生产数据或提取凭据。无发现只表示已检查范围内未发现问题，不代表安全保证。
