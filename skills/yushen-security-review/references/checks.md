# 认证等专项检查入口

仅在当前改动涉及对应机制时查阅官方文档，记录实际采用版本、查证日期、适用控制与证据。项目已有专项规则优先按其实际约束检查。

| 改动 | 操作参考 |
| --- | --- |
| 身份认证、账号恢复、敏感操作 | [OWASP Authentication](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html) |
| 资源归属和操作授权 | [OWASP Authorization](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) |
| 会话创建、撤销与生命周期 | [OWASP Session Management](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html) |
| 安全日志与敏感数据暴露 | [OWASP Logging](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html) |

按机制选择检查，不将部分检查冒充完整合规认证。无法联网时注明外部文档未核验。
