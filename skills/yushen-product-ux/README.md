# 产品流程与交互

`yushen-product-ux` · 从真实入口检查用户能否少绕路地完成整个目标。

## 何时使用

设计或审查安装、授权、配置、日常操作与失败恢复的完整流程，找出重复输入、多余判断、重复入口或不稳定布局。

## 调用示例

```text
请读取 skills/yushen-product-ux/SKILL.md，
检查这个功能从首次进入到完成目标的路径，给出最小改进建议。
```

## 会得到什么

清楚的目标与完成结果、首次和日常使用路径、必要步骤的理由，以及状态反馈、恢复方式和可观察验收项。

不以少点击省略必要授权或高风险确认，不以视觉精美代替任务成功。没有真实用户测试时，只能报告设计检查或内部测试。
