# 代码质量与复用审查

`yushen-code-quality-review` · 先找已有能力，再判断新增实现是否值得维护。

## 何时使用

审查 PR 的功能证据、死代码候选、重复实现、无价值包装或可复用方案。重点是当前改动引入或加剧的问题。

## 调用示例

```text
请读取 skills/yushen-code-quality-review/SKILL.md，
审查这个 PR 的代码质量与复用机会，先给反馈草稿。
```

## 会得到什么

带位置、证据、影响与建议的反馈；必要时附统一口径的计数和替代方案比较，分清阻塞缺陷与非阻塞建议。

审查只读，不自动删除、重构、安装依赖或采用外部代码。候选告警不等于已确认死代码；无法验证的范围会明确说明。
