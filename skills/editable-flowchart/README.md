# 可编辑流程图

`editable-flowchart` · 从文字、文档或参考图生成可继续修改的本地图。

## 何时使用

创建或调整流程图、技术路线和研究路线图。默认本地 SVG；用户指定 draw.io、Mermaid 或其他格式时优先遵循指定格式。

## 调用示例

```text
请读取 skills/editable-flowchart/SKILL.md，
把这段流程画成可编辑 SVG，精确保留标签，先在本地交付。
```

## 会得到什么

独立文字、形状与连线组成的源文件，按需附实际渲染的预览和编辑能力说明。PNG/JPG 只作预览，栅格化部分会说明限制。

默认不需要飞书、Lark CLI 或 OAuth。只有明确要求飞书时才加载发布参考，并核对目标、可见范围与权限；不同编辑器的导入能力需分别验证。
